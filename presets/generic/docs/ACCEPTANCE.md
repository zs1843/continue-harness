# 验收标准

每条需求必须拆成可验证的验收标准，并关联测试、日志、报告或其他可审计证据。

允许的收口状态：`verified`、`deferred`、`blocked`。延期和阻塞必须记录原因、确认人和后续条件。

在实现前定义验收标准。需求列引用 manifest 中的有效输入编号，可附 #章节；实现项和证据列填写项目相对文件路径。输入或实现变化后重新验证。表格为空表示尚未配置验收，不能证明任务完成。
