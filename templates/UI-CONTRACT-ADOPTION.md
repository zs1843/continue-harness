## 首次使用流程

首次使用时，Agent 必须先扫描页面和组件，并建立或更新 `UI-COMPONENT-INVENTORY.md`。
已有组件默认标记为 `protected`，不需要先确认是否加入清单。

扫描完成后，Agent 必须展示当前 Token 状态、组件保护规则、证据目录和新增视觉值的确认规则，
再询问用户是否需要补充 UI 规范或 Token。用户补充的内容先标记为 `candidate` 或 `pending`，
获得确认后才能写入唯一 Token 真值或规范文件。

处理结果必须记录日期、确认人、扫描范围和补充内容，并将状态改为 `confirmed`。
规范发生重大变化时重新执行本流程。
