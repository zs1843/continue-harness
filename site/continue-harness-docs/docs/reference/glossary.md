# 术语表

| 术语 | 含义 |
| --- | --- |
| Core | 维护通用协作状态、验证编排和追溯关系的运行能力 |
| Intake | 通过对话确认项目事实、未知项和输入适用性的过程 |
| Input | 需求、约束或任务相关证据的登记项 |
| Acceptance item | 可判断完成与否的验收标准 |
| Evidence | 支持某项实现或验收结论的可复核记录 |
| Snapshot | 绑定任务、输入、验证结果和上下文的交接记录 |
| Extension | 仅在项目明确需要时启用的专门能力 |
| Skill | Agent 调用的工作流程说明 |
