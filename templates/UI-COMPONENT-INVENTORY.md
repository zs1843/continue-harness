# UI Component Inventory

本清单记录项目已有页面、公共组件、业务组件和控件。清单内对象默认属于已有 UI，状态为
`protected`；清单不是业务组件库的第二份实现。

## 状态

- `protected`：已有 UI，默认不可修改。
- `wrapped`：通过包装组件复用已有能力。
- `page-specific`：仅服务单个页面。
- `candidate`：待确认是否纳入公共 UI 体系。
