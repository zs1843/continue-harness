# SOP overview

The complete workflow is:

1. Create or adopt a project.
2. Confirm basic project facts through Intake when the project provides an intake file.
3. Place and register source inputs.
4. Inspect and analyze evidence.
5. Create a stable task ID.
6. Load only the evidence needed by the task.
7. Implement and run the matching verification mode.
8. Save a snapshot, history, and current status.

See the [workflow guide](/en/guide/overview) for the short path and [verification guide](/en/guide/verification) for the completion gates.
