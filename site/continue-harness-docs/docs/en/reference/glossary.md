# Glossary

| Term | Meaning |
| --- | --- |
| Core | Framework-neutral runtime for configuration, diagnostics, execution, and reports |
| Product Profile | Rules caused by product shape |
| Platform Adapter | Runtime and acceptance rules |
| Stack Adapter | Framework and toolchain rules |
| Input | Registered PRD, RP, UI, API, or asset evidence |
| Task | Stable ID connecting evidence, implementation, verification, and snapshots |
| Resume | Read-only collaboration handoff state |
| UI Contract | Project-owned component, Token, and visual boundary record |
| Skill | An invokable Agent workflow |
