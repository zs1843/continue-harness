# 视觉设计依据

视觉设计依据是可选输入，仅在项目任务和验收标准确实涉及视觉时使用。它不属于通用 Harness 流程的前置条件。

## 权威与确认

项目维护唯一的机器可读视觉决策来源，并记录来源、版本、状态和适用范围。已有视觉资料或项目约定是候选依据；Harness 或 Agent 生成的候选值在负责人确认前不属于权威事实。

## 既有项目

只读发现能力可用于整理已有视觉样式中的候选值。发现结果必须结合项目资料和负责人确认后，才能纳入项目决策。发现过程不会自动重写项目内容。

## 验收边界

没有经确认的视觉依据和可复核基线时，不得宣称视觉还原已通过。其他验证模式通过不能替代视觉验收。没有相关需求的项目无需创建视觉记录。
