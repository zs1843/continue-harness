# Why a harness

This page describes the motivation behind continue-harness.

During ongoing development, requirements change, implementation can lose its acceptance links, and decisions can be lost across sessions or collaborators. Continue Harness connects requirements, implementation items, acceptance items, evidence and handoff state so collaborators can assess delivery and recover project context. The toolchain determines execution and verification methods, not the scope of this collaboration protocol.
