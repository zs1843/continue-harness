# RP 低保真原型输入

## 用途

保存低保真原型、交互草图、产品线框图、流程原型和状态跳转说明。

## 支持形式

HTML、Markdown、RP、JSON、YAML、PDF、图片、Axure 导出、墨刀等原型工具导出内容。不得仅依靠扩展名判断用途，应结合清单、README 和内容识别。

## 主要决定

页面结构、信息分组、字段位置、操作入口、页面跳转、浮层弹窗、基础交互、页面状态和流程顺序。

## 优先级

RP 不能覆盖高保真 UI 已明确的视觉细节。没有高保真 UI 时，RP 可作为视觉推断依据，并在覆盖矩阵中标记“视觉依据：低保真 RP”。

## 修改规则

原始 RP 默认只读。抽取结论写入项目事实文档、覆盖矩阵和任务快照。
