# 高保真 UI 输入

## 用途

保存高保真 HTML 稿、Figma/Sketch 导出、截图、标注稿、切图、图标、品牌资产、设计系统和高保真交互原型。

## 主要决定

页面视觉结构、信息层级、颜色、字体、字号、字重、行高、间距、圆角、阴影、边框、图标、图片、组件外观、响应式表现、动效和 Design Token。

## 优先级

高保真 UI 是视觉与 Token 的最高优先级来源。Agent 不得因为“更现代”或通用偏好擅自重构。

## 修改规则

原始 UI 默认只读。Token 抽取写入 `docs/design/tokens.json`，中文解释写入 `docs/design/TOKENS.md`，变更写入任务快照和 `docs/history/CHANGE_HISTORY.md`。
