# `demo-h5`：从 PRD 到可展示的证据

`demo-h5` 是仓库内的 Consumer H5 示例项目。它用全局 `continue-harness 1.2.4` 脚手架创建；本仓库源码 CLI 的版本为 `0.1.0`。两套版本的输出不能混作同一次验证结果。

## 当前进度

2026-09-21，项目已登记 T001《入境游 AI 行程助手 PRD》。需求描述了路线搜索与比较、逐日行程、天气事实与提示、独立对话、变更预览与撤销。`continue-harness inputs inspect --json` 确认 PRD 文件存在、哈希未变化、输入清单没有问题；其状态仍为 `draft`。

业务页面、覆盖矩阵和业务交互验证尚未完成。因此当前最有说服力的画面是**需求如何进入工作流**，不是脚手架首页。
