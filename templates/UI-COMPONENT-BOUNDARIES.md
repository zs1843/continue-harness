# UI Component Boundaries

## 已有组件

已有组件默认受保护：

- 不因新增 Token 自动替换已有组件样式；
- 不进行全量视觉统一、批量迁移或无关重构；
- 不改变公开 Props、Events、Slots、DOM 结构或交互语义；
- 不通过全局样式覆盖已有组件来适配新页面；
- 新需求优先使用组合、包装组件或新增组件解决。

未进入组件清单的历史组件也不得被视为可自由修改，需先补入清单或明确状态。

## 二次确认

修改 `protected` 组件前，必须取得用户明确确认，并列出：

```text
组件名称：
修改原因：
影响页面：
视觉/交互变化：
是否影响公开 API：
为什么不能通过新组件或包装组件解决：
回滚方式：
```

确认后的修改仍只能触及任务范围，并在变更历史中记录旧行为和新行为。

## 新组件

- 新组件只能直接使用 `stable` Token；
- `candidate`、`pending` 和 `legacy` Token 使用前必须确认；
- 组件专属值只服务一个页面时标记为 `page-specific`；
- 新组件完成后补充使用示例、公开接口和状态说明。
