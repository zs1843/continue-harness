# Glossary

| Term | Meaning |
| --- | --- |
| Core | Runtime capabilities for shared collaboration state, verification orchestration, and traceability |
| Intake | Conversation-led confirmation of project facts, unknowns, and input applicability |
| Input | A registered requirement, constraint, or task-relevant evidence source |
| Acceptance item | A criterion that can be evaluated as complete or incomplete |
| Evidence | A reviewable record supporting an implementation or acceptance conclusion |
| Snapshot | A handoff record bound to a task, inputs, verification results, and context |
| Extension | A specialized capability enabled only for an explicit project need |
| Skill | A workflow instruction callable by an Agent |
