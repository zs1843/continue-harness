# Problems solved

continue-harness addresses recurring collaboration failures:

- Requirements and design evidence are scattered across chat, files, and screenshots.
- Agents load too much context or start guessing when context is missing.
- A successful build is mistaken for complete requirement coverage.
- Generated API files and manual changes overwrite each other.
- Provider-specific Agent rules drift apart.

The harness responds with registered inputs, task-scoped evidence, requirement closure, managed-file protection, one constraint authority, and resumable reports.
