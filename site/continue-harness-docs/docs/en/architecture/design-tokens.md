# Visual design evidence

Visual design evidence is optional and applies only when project tasks and acceptance criteria involve visual behavior. It is not a prerequisite for the common Harness workflow.

## Authority and confirmation

The project maintains one machine-readable source for confirmed visual decisions, including source, version, status, and scope. Existing references and project conventions are candidate evidence; values proposed by the Harness or an Agent are not authoritative until confirmed by the project owner.

## Existing projects

Read-only discovery can help identify candidate values from existing visual styles. Candidates must be reviewed against project evidence and confirmed before becoming project decisions. Discovery does not rewrite project content.

## Acceptance boundary

Without confirmed visual evidence and a reviewable baseline, do not claim visual fidelity has passed. Other verification modes do not substitute for visual acceptance. Projects without relevant requirements do not need visual records.
