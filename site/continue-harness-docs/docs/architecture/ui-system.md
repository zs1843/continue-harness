# 可选视觉与组件记录

视觉依据、组件规范和设计取值都属于可选输入。通用 Harness 流程不要求这些材料；只有已确认的项目事实或验收标准表明相关时，才应纳入。

仓库中的部分模块可以检查结构化流程、布局、调整记录或组件清单。这些专项路径需要显式配置，并依据对应证据验证。它们的存在不表示默认依赖、自动设计决策或对所有项目的普遍支持。

## 证据与所有权

项目负责维护其来源材料、已确认的设计决策、组件规范和获准例外。生成的清单与候选取值在审阅前均为暂定结果。协议样例通过，不代表真实项目的视觉或交互验收已经通过。

## 边界

缺少已确认来源或可审阅基线时，应将该能力报告为未配置或未验证。不能用无关检查证明视觉一致性；对于不适用的项目，也不应添加视觉或组件记录。
